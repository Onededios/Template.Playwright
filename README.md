# Template.Playwright

## Features

- TypeScript & Node ≥ 20 ready
- Pre‑configured Playwright Test Runner with trace, video & HTML reports.
- ESLint & Prettier presets for consistent code style.
- Apache‑2.0 licensed – free for commercial and open‑source projects.

## Contributing

Fork the repo and create your branch.

Commit your changes following Conventional Commits.

Run npm run lint && npm run test locally – make sure everything passes.

Submit a pull request. Your contribution must keep the build green.

All contributors must certify that they wrote the code or have the right to submit it by adding a “Signed‑off‑by” line (git commit -s) as per the Developer Certificate of Origin.

## Quick Start

```bash
# 1. Clone the repository
$ git clone https://github.com/YOUR-ORG/playwright-test-template.git

# 2. Install dependencies
$ cd playwright-test-template
$ npm install

# 3. Run all tests locally
$ npm run test

# 4. Open the HTML report
$ npx playwright show-report
```
